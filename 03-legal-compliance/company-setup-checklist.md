# 公司设立清单 (Company Setup Checklist)

Owner: Lightman · Status: Active · Last reviewed: 04/10/2026

> 结果（编号、日期）填回 `00-company/company-profile.md`。

## 1. 创始人之间先说清楚（注册前）
- [ ] 股权分配、vesting（建议 4 年，1 年 cliff）、good/bad leaver 条款
- [ ] 角色与决策权（谁是 CEO、谁有最终决定权）
- [ ] 每人投入时间（全职/兼职）、是否有现任雇主 IP 冲突 ⚠️ 检查现有雇佣合同的 IP / 竞业条款
- [ ] 写成 **Shareholders' Agreement**（律师起草）→ ADR-0002

## 2. 实体注册
- [ ] 每位董事申请 **Director ID**（myGovID / myID，ABRS）
- [ ] ASIC 查名 + 检查 IP Australia 商标冲突
- [ ] 注册 Pty Ltd（ASIC，或通过律师/会计）：至少 1 名董事且常居澳洲；股东、股份类别、注册地址
- [ ] 决定 Constitution（创业公司建议自定义章程，便于未来融资、ESOP）
- [ ] 申请 ABN（选 "company"）、TFN
- [ ] GST：决定是否自愿注册（早期常注册以抵扣进项）
- [ ] 股权证书、成员登记册 (register of members)、董事会议记录簿

## 3. IP 与品牌
- [ ] 创始人签 **IP Assignment Deed**（注册前已产生的代码、设计、文档、域名转给公司）
- [ ] 商标申请 "careKind" / "careKind AI"：Class 9、42、（考虑 44）
- [ ] 域名：carekind.com.au（需 ABN）、carekind.ai、carekind.com
- [ ] 社交账号占位：LinkedIn 公司页（aged care 采购人在这里）、X、Instagram

## 4. 银行与财务
- [ ] 公司银行账户（与个人完全分开）
- [ ] 记账：Xero / MYOB，连接银行
- [ ] 费用报销规则、公司卡
- [ ] 找注册税务代理；设定 BAS 周期（季度）

## 5. 基础工具与安全
- [ ] Google Workspace / M365 + 强制 MFA
- [ ] 密码管理器（1Password / Bitwarden）
- [ ] 文件存储与权限结构（与本仓库的 SSOT 对应）
- [ ] 云账号：root 账号上硬件密钥 MFA，账单告警

## 6. 第一位员工前
- [ ] 注册 PAYG withholding、STP 兼容薪资软件
- [ ] WorkSafe Victoria WorkCover 保险
- [ ] Super 默认基金 / stapled fund 流程
- [ ] 标准雇佣合同 + 保密 + IP 条款（律师）
- [ ] 见 `05-hr-teams/policies/employment-compliance.md`

## 7. 政府支持（可选，值得查）
- [ ] R&D Tax Incentive（从第一天保留研发记录）
- [ ] ESIC 资格自评（吸引天使投资人）
- [ ] VIC 创业资助（LaunchVic 等）⚠️ 需核实当期项目
- [ ] 联邦 Industry Growth Program ⚠️ 需核实
- [ ] 各州/联邦 aged care 创新、数字健康类资助 ⚠️ 需核实
