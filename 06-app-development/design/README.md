# 设计

Owner: Lightman (PO) · Last reviewed: 04/10/2026

## 用途
UX 原则、无障碍、设计系统。

## 内容
- **DESIGN.md** — 设计规范（Source of Truth）：风格、tokens、排版、组件、状态与 AI 内容、无障碍、文案
- **DESIGN.html** — 给人看的版本（由 DESIGN.md 自动生成，用浏览器打开：有目录、颜色色块；不要手改）
- **COMPONENTS.md** — 组件规格（Source of Truth）：每个常用组件的用途、变体、状态、键盘与无障碍、文案；**COMPONENTS.html** 是它的阅读版（自动生成）
- design-system/ — tokens.json（数值唯一来源）、生成的 tokens.css、预览页
- ux-principles.md
