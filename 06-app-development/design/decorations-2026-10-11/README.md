# careKind 装饰配图 · 11/10/2026

Owner: Lightman · Status: Draft · Last reviewed: 11/10/2026

按用户提供的两张 Microva+ 设计图生成原创黑色手绘线描。只借用轻盈线条、温暖情绪与留白；角色均为虚构。
仓库 brand-guide.md 的视觉定义仍为待定，因此本组是用户指定方向的候选素材，不替换全局设计系统。

## 素材与用途

| 文件 | 建议位置 |
| --- | --- |
| companionship-v1.png | 首页介绍、陪伴照护、团队故事 |
| nurse-review-v1.png | 护士审核流程、记录功能说明 |
| hands-and-heart-v1.png | 品牌价值、照护理念、标题旁 |
| quiet-moment-v1.png | Time back to care 区块、页尾 |

所有原图保留模型生成的 alpha 透明度。黑色线条用于白色或浅色底；建议显示宽度 140–320 px，
人物插图可用 240–420 px。不要作为功能按钮图标，避免大面积重复堆叠。
纯装饰使用空 alt；承担信息表达时按实际场景写 alt。
PNG 为位图，尚未矢量化。未接入 App 或发布线上。

## 预览与生成记录

- preview.html：浅底素材预览，适配桌面与手机。
- prompts.json：每张图的完整实际 prompt、生成方式和原始文件出处。
- 原始输出采用内置 image_gen；没有通过 CLI fallback。
- alpha、尺寸与视觉验收结果见 verification.json。
- 桌面和手机预览截图为 gallery-desktop.png、gallery-mobile.png。
