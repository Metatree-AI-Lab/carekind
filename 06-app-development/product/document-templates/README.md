# 文书模板（careKind 自有）

Owner: Lightman · Last reviewed: 18/10/2026

## 用途
careKind 自己设计的澳洲住宿养老护理文书 Markdown 模板。产品团队用它定义 AI 起草的字段和审核规则；试点机构可以拿来对照自己的 CMS 表单；Demo 工作区用它的结构生成虚构示例数据。

## 内容
- `index.md` — 全部模板清单和使用说明
- `daily-*.md` — 日常记录（progress note、交接、饮食饮水、家属沟通）
- `incident-*.md` — 事件与合规（incident、跌倒后、用药事件、SIRS 准备、投诉）
- `clinical-*.md` — 临床监测（ABC 行为、约束性措施、PRN、疼痛、伤口、病情恶化）
- `plan-*.md` — 评估与计划（入住、护理计划复核、病例会议）
- `eol-*.md` — 姑息、临终与死亡

## 怎么用
1. 先看 `index.md` 找到对应事件的模板。
2. 机构使用前，按自己的政策和 CMS 字段调整；模板不是法律意见，也不是机构正式政策。
3. 标 `🧑 人工` 的字段必须由护士或经理自己填写和确认。
