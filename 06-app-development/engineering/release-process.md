# 发布流程 (Release Process)

Owner: Lin (Tech Lead) · Status: Draft · Last reviewed: 04/10/2026

1. 功能完成 → staging 部署
2. 回归测试 + AI 评测（如涉及 AI）
3. 临床相关变更：临床顾问签字
4. 发布说明（面向客户：变更内容、是否影响记录格式）
5. 生产部署（可灰度：先内部 → 单个试点 home）
6. 监控 24–48 小时：错误率、AI 错误报告、采纳率
7. 回滚方案随时可用

**影响记录格式或 AI 行为的重大变更需提前 {{TBD: 7}} 天通知客户。**
