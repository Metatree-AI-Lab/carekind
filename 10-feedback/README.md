# 10 Feedback — 原始反馈记录 (RAW)

Owner: Lightman · Status: Active

> 🚫 **本目录只存放人工录入的原始反馈，原文照录，不经过 AI 编写、改写、润色、翻译或总结。**
> Raw, verbatim feedback only. No AI-generated or AI-edited content.

## 规则
1. **原话照录**：用户怎么说就怎么记，包括语法错误、口语、原始语言（中文/英文/其他语言都保留原样）。
2. **人工录入**：由团队成员亲手记录或直接粘贴原始来源（邮件、聊天、表单导出）。
3. **AI 不得写入或修改**：Claude 和其他 AI 工具可以**读取**本目录做分析，但**不能新建、编辑、改写或删除**这里的任何反馈文件。
4. **分析写在别处**：基于反馈的总结和洞察写到 `06-app-development/research/synthesis.md`，并引用原始文件路径。
5. **一条反馈一个文件**，记录后不再修改；需要补充就另建一个文件，注明关联文件。
6. **隐私**：不要记录住户姓名、房号、健康细节，也不要记录可识别个人身份的信息；受访者用代号（RN-01、DON-02）。如果原始反馈里有这些内容，录入的人要在录入时手动替换成 `[已删除]`。删除可识别信息是唯一允许的改动。

## 目录
```
nurses/      护士、护理员（RN / EN / PCW）
```

`YYYY-MM-DD_来源代号_渠道.md`，例：`2026-10-12_RN-03_interview.md`
