# Marketing Copy Check

1. Read `07-marketing-ops/marketing/marketing-compliance.md` and `07-marketing-ops/brand/brand-guide.md`.
2. Run every checklist item against the content. Also run `tga-boundary-check` on the content's wording.
3. Output a table: issue | quote | rule | severity (block/fix/suggest) | suggested rewrite.
4. Check that every statistic or claim has a cited, verifiable source. If it doesn't, mark it `block`.
5. Make sure the copy uses Australian English, says "older people/residents", and keeps the nurse in control.
6. Do not publish anything. The output is a review only (🧑 a human approves publication).
