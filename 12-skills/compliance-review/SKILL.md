# Compliance Review

1. Read `03-legal-compliance/compliance-register.md`, `00-company/company-profile.md`, `05-hr-teams/team-members.md`, `04-security/vendor-subprocessor-register.md`, and `03-legal-compliance/references/` (if present).
2. Check for changes in company facts that make ⚪ items applicable, e.g. new employees, revenue thresholds, new states, new data types or new sub-processors.
3. If web access is available, check the official sources for updates on items marked `⚠️ 需核实` and on any upcoming commencement dates (oaic.gov.au, agedcarequality.gov.au, health.gov.au, tga.gov.au, fairwork.gov.au, ato.gov.au, worksafe.vic.gov.au, sro.vic.gov.au). Cite the URLs. If you are offline, say so.
4. Produce a report: changed items, overdue 🔴 items with owners, upcoming deadlines (next 90 days), and verified/unverified updates.
5. Propose edits to the register. Apply them only after 🧑 human confirmation (in headless runs, write the proposal to the run log only). Add a row to the 复核日志.
6. End with the disclaimer: 运营参考，不是法律意见.
