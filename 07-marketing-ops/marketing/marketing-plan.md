# 营销计划 (Marketing Plan)

Owner: Lightman · Status: Draft · Last reviewed: 04/10/2026

## 阶段 0–1 目标：信任与线索，而非规模
## 渠道（按优先级）
| 渠道 | 动作 | 指标 |
|---|---|---|
| 创始人 LinkedIn | 每周 2 篇：访谈洞察（去标识化）、aged care 文书话题、建造过程 | 互动、私信 |
| 人脉与引荐 | 顾问、护士网络、aged care 从业者 | 会议数 |
| 行业组织与活动 | Ageing Australia（行业峰会）、ACCPA 等行业协会活动 ⚠️ 核实当前组织名称、ACN（Australian College of Nursing）、州级 aged care 网络、创新/健康科技活动 | 会议数 |
| 内容 | 博客/指南：e.g. "How to write person-centred progress notes"、"Aged Care Act 2024 documentation checklist" | 自然流量、订阅 |
| 官网 | 落地页 + 等候名单 + 安全与隐私页 + 预约演示 | 转化率 |
| 播客 / 媒体 | aged care 行业媒体（Australian Ageing Agenda、HelloCare 等）⚠️ 核实 | 曝光 |

## 内容支柱
1. 护士的一天（文书负担的真实故事）
2. 写好记录（实用指南——即使不用我们也有价值）
3. 合规解读（新法、新标准对记录意味着什么）
4. 负责任的 AI（我们如何做安全、隐私）

## 官网必备页面
首页 · 产品 · 安全与隐私（数据驻留、不训练、审核流程）· 关于我们 · 隐私政策 · 预约演示 / 等候名单
