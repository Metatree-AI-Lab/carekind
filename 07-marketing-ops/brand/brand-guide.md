# 品牌指南 (Brand Guide)

Owner: Lightman · Status: Draft · Last reviewed: 04/10/2026

## 定位（待访谈验证）
**For** Australian aged care providers **who** struggle with nursing documentation burden, **careKind AI is** a documentation assistant **that** turns nurses' spoken notes into accurate, respectful records in seconds. **Unlike** generic AI scribes built for GP consults, **careKind** is built for aged care workflows, multilingual care teams, and the Aged Care Quality Standards — with the nurse always in control.

## 信息层级
1. **Time back to care** — 把时间还给照护
2. **Nurse stays in control** — 护士审核每一条
3. **Built for Australian aged care** — 模板、语言、标准、数据在澳洲
4. **Private by design** — 数据留在澳洲、不训练模型
