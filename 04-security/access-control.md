# 访问控制 (Access Control)

Owner: Lin (Tech Lead) · Status: Draft · Last reviewed: 04/10/2026

## 原则
最小权限 · 需要知道 · 职责分离 · 默认拒绝 · 一切可审计

## 产品内角色（客户侧）
| 角色 | 可以 |
|---|---|
| Care worker (PCW) | 口述、查看/编辑自己的草稿、提交审核（按机构政策） |
| Nurse (EN/RN) | 以上 + 审核确认、查看本单元住户记录 |
| Clinical manager | 以上 + 模板管理、质量报表、审计查看 |
| Provider admin | 用户管理、SSO 配置、数据导出 |

## 内部访问
| 系统 | 谁 | 方式 |
|---|---|---|
| 生产数据库 / 客户数据 | 默认无人；on-call 工程师经审批临时访问 | 限时提权 + 审计 + 事后复核 |
| 客户支持查看 | 支持人员，需客户在工单中授权 | 产品内"支持模式"，留痕 |
| 云管理控制台 | CTO + 指定工程师 | SSO + 硬件密钥 MFA |
| 财务 / 银行 | 创始人 | MFA，双人审批大额付款 |

## 生命周期
- 入职：按角色模板开权限（`05-hr-teams/onboarding/onboarding-checklist.md`）
- 变更：角色变动当天调整
- 离职：**最后工作日当天**撤销全部访问、回收设备
- 每季度：权限审查并留记录
